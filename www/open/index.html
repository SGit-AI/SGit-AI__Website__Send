Open

Everything that unlocks a file is after the # in the link, which your browser never sends to any server. Paste a link, a friendly token, or a read key; the file is decrypted here.

Nothing you paste here is uploaded.

What this page can open

Looks likeIt isWhat happens
#abc123def456/43 charactersa transfer with its keydownloaded, decrypted here, saved with the name that was inside the ciphertext
#abc123def456a transfer, link onlythis page asks for the key that travelled separately
#river-cloud-3847a friendly tokenthe transfer id and the key are both derived from the token, here
#sgit_public_read_…:vaultida vault's read keyevery file and every version, read only, decrypted here; also sgit clone-able
#sgit_private_vault_…:vaultida vault keyopens too, with a warning: it is write access and should not have travelled in a link

A link made on send.sgraph.ai opens here too, and the other way round: the formats are the same. QR codes and friendly tokens.
