Keys

Every key this site made or was given, on this device, in this browser. This is what was missing before: a vault key that is not written down is a vault that is lost, and a key pasted into a chat is a key that is kept by someone else.

What this keyring is, and is not. It is one JSON document in this browser's storage, in plaintext: anyone with this device and this profile can read it, and clearing site data deletes it. It is not synced and not uploaded. For keys that matter, export the document to a password manager, or to secrets.sgit.ai's passkey-unlocked keyring once it ships. Vaults and keys says where each kind of key should live.
