--- title: send.sgit.ai, send a file, keep the key description: Send a file to anyone, encrypted in your browser before it leaves. The server never sees the file, its name or the key. Hand over the link as a QR code, or keep the files in a vault you can open again, update, and clone with sgit. ---

Send a file. Keep the key.

The file is encrypted here, in your browser, with its name inside the ciphertext. The server gets bytes it cannot read. You get a link, a QR code, or a token you can say aloud; whoever has it gets the file, and nobody else does, the server included.

Beta: uploading needs an access token. Set one in Settings, or read how to get one. Opening a link needs nothing.
Drop a file here, or click to choose Encrypted in this browser before upload · under 4 MB for a one-off transfer · any size into a vault

    Several files go into a vault, as one commit.

    For a vault the link carries the read key; the vault key stays on this device.
