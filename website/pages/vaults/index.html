Vaults

A vault is a folder of files, encrypted here, versioned like git, that you can open again, add to, and share read-only. The vault key stays on this device; the read key is the one you hand out. Anyone with the read key can also sgit clone it on a laptop.

Beta: creating and writing to a vault needs an access token; set one in Settings. Opening a read key needs nothing.
